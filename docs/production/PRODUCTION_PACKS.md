# PRODUCTION PACKS

**Status:** [PROPOSTA V1]

Production Pack é uma recipe versionada. O agente adapta parâmetros dentro dos limites do pack; não reinventa a fábrica.

## PACK-PRESENTER

Uso:
- treinamento simples;
- aulas;
- boletins;
- comunicados.

Faixa de composição:
- presenter: 80–90%
- deterministic visuals: 5–15%
- b-roll: 0–10%
- motion transfer: 0–5%

Objetivo: custo baixo, consistência alta, throughput alto.

## PACK-DYNAMIC

Uso:
- training premium;
- curso;
- masterclass;
- autoridade;
- workshop.

Faixa:
- presenter: 55–70%
- slides/graphics: 10–20%
- b-roll: 10–20%
- motion: 5–10%

Objetivo: default balanceado.

## PACK-PREMIUM

Uso:
- VSL;
- autoridade premium;
- apresentação importante.

Faixa:
- presenter: 40–60%
- deterministic visuals: 10–20%
- cinematic b-roll: 15–25%
- motion: 10–20%

## PACK-SIGNATURE

Uso:
- campanha;
- brand film;
- lançamento;
- hero asset.

Maior liberdade visual, custo e human review.

## Recipe dimensions

Cada versão define:
- allowed shot types;
- min/max presenter ratio;
- max cinematic ratio;
- quality target;
- default resolution;
- retry policy;
- QC policy;
- human review policy;
- cost policy;
- allowed routing classes;
- deterministic fallback rules.

## Rule

`objective + pack + policy + budget` formam a restrição da produção.

Provider não faz parte da identidade do pack.
