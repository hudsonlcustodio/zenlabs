# CONTENT DENSITY & UI COPY

## Regra de escrita

Uma ação = um verbo.

Exemplos:
- Analisar
- Aprovar
- Revisar
- Produzir
- Agendar
- Publicar
- Resolver
- Reprocessar

Evitar:
- “Clique aqui para analisar a sua produção”
- “Deseja realmente continuar com esta ação?”
- “Este conteúdo será processado pelo sistema”

Preferir:
- `Analisar`
- `Continuar`
- `Produção iniciada`

## Tooltips

Usar para:
- conceito técnico;
- métrica;
- ícone;
- consequência não óbvia.

Não usar para esconder:
- erro;
- risco;
- custo;
- consentimento;
- ação irreversível.

## Status

Texto curto + cor + ícone quando necessário.

Exemplos:
- Ativo
- Gerando
- QC
- Pronto
- Bloqueado
- Atenção
- Falhou

## Informação secundária

Abrir em:
- drawer;
- row expansion;
- tooltip;
- detail pane.

Não ocupar o primeiro nível visual.

## Regra de truncamento

Textos longos:
- 1 linha em tabelas;
- 2 linhas em cards;
- expandir sob demanda.

## Empty states

Máximo:
- título curto;
- uma frase;
- uma ação.

Exemplo:
`Nenhuma produção ativa`
`Crie uma produção para começar.`
`+ Nova produção`
