# APP SHELL

## Desktop

- Sidebar expanded: 224px
- Sidebar collapsed: 64px
- Topbar: 52px
- Content gutter: 20–24px
- Main background: Pearl
- Working surfaces: White
- Border: 1px Border
- Shadows: none ou muito sutis

## Sidebar

Ordem:

- Início
- Clientes
- Ideias
- Operação
- Produção
- Calendário
- Biblioteca
- Performance

Secundário:
- Configurações
- Equipe
- Integrações
- Billing

### Active state
- Mist background discreto
- marcador Lime de 2px
- texto Obsidian

### Collapsed
- símbolo ZenLabs
- ícones
- tooltip no hover/focus

## Topbar

Mostrar apenas o necessário:
- breadcrumb/contexto;
- busca global opcional;
- notificações;
- perfil.

Não duplicar títulos/menus da sidebar.

## Page header

Padrão:
- título curto;
- contexto/estado;
- 1 ação primária;
- no máximo 2 ações secundárias visíveis.

Ações menos frequentes vão em menu `…`.
