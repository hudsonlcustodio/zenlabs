# RESPONSIVE & ACCESSIBILITY

## Desktop-first
Internal operations:
- 1280px+ primary
- 1440/1600 preferred
- 1920 uses width intelligently

## Tablet
- sidebar collapses
- table columns reduce
- detail in drawer

## Mobile internal
Permit:
- alerts
- exception triage
- approval
- production status

Evitar:
- full Scene Graph editing
- dense cost diagnostics

## Client portal
Mobile-first compatible.

## Accessibility
- WCAG 2.2 AA baseline
- visible focus
- keyboard navigation
- labels on form controls
- color never sole status signal
- contrast checked
- target size adequada em mobile
- reduced motion support

## Small typography rule
Desktop can be compact, but:
- never below 12px for meaningful UI copy;
- 13–14px is default operational text;
- 14px+ for mobile.
