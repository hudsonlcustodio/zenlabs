# CORES E ESTADOS

## Base aprovada
- Pearl `#F5F6F3`
- White `#FFFFFF`
- Mist `#EEEFEA`
- Obsidian `#0A0A0C`
- Graphite `#5E6068`
- Steel `#7E8089`
- Border `#DEDFDA`
- Electric Lime `#C6FF3D`
- Signal Violet `#7C5CFF`

## Semântica

### Electric Lime
Usar para:
- botão primário;
- item ativo;
- progresso;
- sucesso estratégico;
- indicador “tudo certo”.

### Signal Violet
Usar para:
- recomendação de IA;
- Clone digital;
- análise inteligente;
- produção em andamento quando semanticamente útil.

### Verde
Sucesso operacional.

### Laranja
Atenção.

### Vermelho
Erro, bloqueio, risco.

### Azul
Informação / agendamento / integração.

## Regra
Nunca usar 5 cores competindo na mesma região.

Em dashboards, cada cor deve carregar significado estável.
