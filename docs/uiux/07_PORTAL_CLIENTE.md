# PORTAL DO CLIENTE — DIREÇÃO CANÔNICA

## Objetivo
Transmitir:
- clareza;
- confiança;
- acompanhamento;
- resultado.

O portal não é uma ferramenta de produção.

## Navegação

PRINCIPAL
- Visão geral
- Calendário
- Conteúdos
- Desempenho

CONTA
- Conta e financeiro

SUPORTE
- Ajuda

## Perfil
Bloco fixo no rodapé da sidebar:
- avatar
- nome
- empresa
- menu `…`

## Linguagem
Sempre simples.

Exemplo:
- `Em produção`
- `Programado`
- `Publicado`
- `Tudo dentro do planejado`

Evitar:
- `QC`
- `roteamento`
- `provedor`
- `fallback`
- `job`
- `fluxo`

## Celular
Portal do cliente é responsivo e deve funcionar integralmente em celular.
