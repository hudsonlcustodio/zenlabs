**Versão:** 1.0  
**Status:** [PROPOSTA CANÔNICA — PRONTA PARA APROVAÇÃO]  
**Idioma da interface:** Português do Brasil  
**Referências visuais:** branding aprovada + telas VYRA anexadas pelo usuário em 01/09/2026.

---

## 1. Princípio central

> **Pouco texto. Hierarquia forte. Densidade controlada. Próxima ação óbvia.**

A interface ZENLABS deve transmitir:
- precisão;
- tecnologia;
- premium;
- clareza;
- operação;
- humanidade.

Não deve transmitir:
- excesso de informação;
- complexidade técnica;
- “dashboard genérico”;
- estética de IA neon;
- linguagem de provedor;
- excesso de textos explicativos.

---

## 2. Regras-mãe de interface

### UX-001 — Português do Brasil
Todo texto visível ao usuário deve estar em PT-BR.

### UX-002 — Compacta, mas legível
A interface usa tipografia menor que um site editorial, porém nunca sacrifica leitura.

### UX-003 — Revelação progressiva
Informação técnica só aparece quando necessária.

### UX-004 — Uma ação principal por região
Botão Lime representa a ação mais importante do contexto.

### UX-005 — Cor com significado
- Lime = ação / progresso / positivo.
- Violeta = IA / Clone / recomendação.
- Vermelho = bloqueio / risco.
- Laranja = atenção.
- Neutros = estrutura.

### UX-006 — Cartões com propósito
Não transformar cada informação em cartão.

### UX-007 — Tabelas e listas para operação
Informação recorrente e comparável deve preferir tabela/lista compacta.

### UX-008 — Cliente vê resultado
Portal do cliente é mais simples e visual que a área interna.

### UX-009 — Operador vê atenção
Área interna prioriza fila de atenção, andamento e exceções.

### UX-010 — Provedor invisível
Nome de provedor não aparece no fluxo padrão.

## 3. Personalidade visual

A ZENLABS combina:
- fundo Pearl;
- superfícies White;
- texto Obsidian;
- bordas suaves;
- Electric Lime pontual;
- Signal Violet pontual;
- ícones lineares;
- raios discretos;

A interface deve parecer um software profissional pronto, não um protótipo.
