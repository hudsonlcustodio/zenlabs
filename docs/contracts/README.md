# MACHINE-READABLE CONTRACTS V2

JSON Schema Draft 2020-12 contracts provide a provider-neutral foundation before database/API implementation.

Included:
- ProductionRequest
- IdentityPack
- ProductionPolicy
- ProductionPack
- Shot
- ProductionPlan
- ProductionBudget
- ProviderCapabilitySnapshot
- MediaJob
- QCResult
- ProductionException

## Rule
When these concepts enter executable TypeScript/Zod contracts, JSON Schema, Zod, API and tests must remain synchronized.

The current schemas define contract intent; they are not evidence of a deployed implementation.
