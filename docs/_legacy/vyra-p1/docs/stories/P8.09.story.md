## User story

COMO administrator, QUERO script and video approval modes configurable per tenant, PARA automation is available without weakening governance.

## Context

FR-AP01 to FR-AP07 and `workflows-state-machines.md` §2.5. AUTO skips only the tenant's own acceptance step, never VYRA QA, and never bypasses brand compliance.

## Acceptance criteria

- **AC-1** Script and video approval modes are independently configurable per tenant as MANUAL or AUTO.
- **AC-2** AUTO script approval requires brand compliance to have passed (T05 precondition).
- **AC-3** AUTO video approval skips only the tenant acceptance step and never substitutes for the T13 human QA verdict.
- **AC-4** `QAPolicy` is modelled as extensible to `HUMAN_REQUIRED`, `AI_ASSISTED` and a future automated policy, with only `HUMAN_REQUIRED` active in MVP.

## BDD examples

- EX-P8-06a GIVEN a tenant with AUTO video approval, WHEN no human QA verdict exists, THEN the item cannot reach READY.
