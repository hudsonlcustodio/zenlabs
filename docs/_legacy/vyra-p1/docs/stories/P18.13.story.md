# Story P18.13 — Status language components and the single string source

- **Story ID**: `P18.13`

## User story

COMO frontend engineer, QUERO um único componente e uma única tabela de strings para os estados do produto, PARA que nenhuma tela invente um sinônimo e que status nunca dependa só de cor.

## Context

`workflows-state-machines.md` §2.1 fixes 21 `ContentItem` states and `VYRA_PRODUCT_EXPERIENCE.md` §21 fixes their labels, tones, indicator shapes and who acts next, plus five secondary vocabularies. PD-02 makes state the product's spine; a screen paraphrasing a state breaks the spine.

## Acceptance criteria

- **AC-1** A `StatusChip` family renders label, tone and indicator from **one** table keyed by the canonical state value. All 21 `ContentItem` states from `workflows-state-machines.md` §2.1 are present; a state added to the state machine without a table entry fails the completeness test.
- **AC-2** Status is never colour-only: the indicator shape differs by class — filled dot (terminal), ring (in flight), half (waiting on a human), square (blocked), triangle (failed) — and the label always accompanies it. A greyscale render test asserts every state remains distinguishable (WCAG SC 1.4.1).
- **AC-3** A **string-source test** fails when a state label is rendered from anything other than the table. A literal state string anywhere in `packages/ui`, `apps/web` or a screen is a failure naming the file.
- **AC-4** `SCRIPT_REVIEW` and `VIDEO_REVIEW` carry the `status-active` treatment and are the only states in the Portal that use lime, per §21.2. A lime status treatment applied to any other state fails the lint.
- **AC-5** The five secondary vocabularies of §21.4 exist in the same table with the same guarantees: twin/voice, knowledge source, publication, provider and subscription. `BLOCKED` reasons render from the closed set of §21.3 with their next action, and a reason outside the set fails.
- **AC-6** Time vocabulary (§21.5) is a primitive: relative under 7 days, absolute beyond, always with `<time datetime>` and the absolute value in `title`, and always with a timezone when it differs from the viewer's.

## BDD examples

- EX-P18-06 GIVEN a state label rendered from a literal string, WHEN the string-source test runs, THEN it fails naming the component.
- EX-P18-30 GIVEN every state rendered in greyscale, WHEN the shape test runs, THEN each state remains distinguishable by indicator shape and label.
- EX-P18-31 GIVEN a `BLOCKED` item whose reason is outside the closed set, WHEN it renders, THEN the completeness test fails naming the reason.

## Verification gate

All 21 content states plus the five secondary vocabularies present and complete against their canonical sources; the string-source test turns red on a seeded literal; the greyscale shape test passes; the lime restriction is enforced; `BLOCKED` reasons render with their next action.
