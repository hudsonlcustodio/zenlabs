## User story

COMO frontend engineer, QUERO que um dado ausente apareça como lacuna e que toda série declare sua idade, PARA que nenhum gráfico transforme falta de coleta em zero.

## Context

`performance.md` §5 and `P14.05` make partial collection a first-class outcome, and `FF-16`/`FR-PF05` guarantee the read path never calls a provider — so the user must be told how old the data is, because no refresh exists. `VYRA_PRODUCT_EXPERIENCE.md` §12.4 calls these the truth rules and §12.5 fixes chart accessibility.

## Acceptance criteria

- **AC-1** A missing value renders as a **discontinuity** in a line or area series and as a hatched cell in a table. Zero-filling and interpolation are not expressible: the series API distinguishes `null` (gap) from `0` (measured zero) and rejects a coerced value.
- **AC-2** Every chart fed by `performance_snapshot` data renders a `Collected {relative}` stamp in `mono-sm`, with the absolute timestamp and the collection bucket in its tooltip. A snapshot-sourced chart without the stamp fails the lint.
- **AC-3** No chart exposes a "refresh from platform" affordance, because none exists (`FF-16`). A collection that has not yet run renders the `absent-by-design` empty state inside the chart frame, naming the next scheduled window.
- **AC-4** A cross-platform aggregate renders with an `indicative` label and an info affordance explaining that platform metric definitions differ (`ASM-PF01`).
- **AC-5** Every chart ships `role="img"` with a generated summary label, and a "View as table" disclosure rendering a keyboard-navigable data table equivalent (§12.5).
- **AC-6** At ≥ 3 series, series are distinguishable by dash pattern or point marker as well as by colour, and a deuteranopia simulation test asserts adjacent series remain distinguishable (§5.5).

## BDD examples

- EX-P19-02 GIVEN a performance series with a missing bucket, WHEN it renders, THEN the line shows a discontinuity and the table shows a hatched cell.
- EX-P19-11 GIVEN a snapshot-sourced chart without a collected-at stamp, WHEN the lint runs, THEN it fails naming the chart.
- EX-P19-12 GIVEN a chart with three series, WHEN a deuteranopia simulation runs, THEN adjacent series remain distinguishable.

## Verification gate

Null and zero are distinct in the series API and render differently; the snapshot-age stamp is present on every snapshot-sourced chart and its absence fails the lint; no refresh affordance exists; the accessible table equivalent is keyboard-navigable; the deuteranopia assertion passes at three or more series.
