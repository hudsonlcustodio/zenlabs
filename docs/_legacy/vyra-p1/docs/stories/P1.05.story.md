# Story P1.05 — packages/config typed environment loading

- **Story ID**: `P1.05`
- **Epic**: `P1` (`docs/epics/epic-P1.md`)

- **Depends on**: `P1.04`
- **IMPLEMENTATION COMPLETE**

## User story

COMO platform operator, QUERO configuration parsed and validated once at boot, PARA a misconfigured process fails immediately instead of failing later in production.

## Context

NFR-12 forbids environments sharing any database, bucket, queue, secret, credential, token or provider key. Configuration is the first place that can be made structurally impossible.

## Acceptance criteria

- **AC-1** The environment schema is declared with Zod and parsed once at process start.
- **AC-2** A missing or malformed key causes a non-zero exit with the offending key named and its value never printed.
- **AC-3** The schema shape makes one credential serving two environments inexpressible.
- **AC-4** `PROVIDER_MODE` is reserved as a key with its allowed values declared, though no provider consumes it until P4.

## BDD examples

- EX-P1-03 GIVEN a required key is absent, WHEN a process boots, THEN it exits non-zero and logs the key name without its value.

## Verification gate

Fail-fast boot test green; FF-20 precondition (no value echoing) respected.
