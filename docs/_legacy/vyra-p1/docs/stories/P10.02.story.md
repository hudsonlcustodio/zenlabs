## User story

COMO content strategist, QUERO every prompt versioned and every output traceable to its version, PARA a regression in output quality can be attributed rather than argued about.

## Context

FR-IN05 and `intelligence-engine.md` §5: prompt templates are versioned and each generated script is traceable to the context and prompt version that produced it.

## Acceptance criteria

- **AC-1** Templates are versioned and immutable once used in a generation.
- **AC-2** Every generation records the template version, the resolved model choice and the retrieval trace identifier.
- **AC-3** A template change creates a new version rather than editing the one in use.
- **AC-4** Templates carry no model identifier; that is routing's concern (FF-09).

## BDD examples

- EX-P10-04 GIVEN a generated script, WHEN its provenance is read, THEN the prompt version, model choice and retrieval trace are all identifiable.

Integration tests on provenance completeness.
