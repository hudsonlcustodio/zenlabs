## User story

COMO administrator, QUERO a brand compliance check that AUTO approval cannot skip, PARA automation never ships off-brand content in the client's name.

## Context

FR-AP03 requires minimum quality controls even in AUTO mode. T05 permits system approval only when policy is AUTO and brand compliance passed. `intelligence-engine.md` §2 lists it as a task.

## Acceptance criteria

- **AC-1** Brand compliance evaluates the script against the tenant's brand and behavioural rule versions from P5.03.
- **AC-2** A failing verdict prevents T05 system approval regardless of the tenant's AUTO setting.
- **AC-3** The verdict and the rule versions used are recorded on the item.
- **AC-4** The task is skippable only by explicit human approval, never by policy configuration.

## BDD examples

- EX-P10-06a GIVEN a tenant with AUTO script approval and a failing brand verdict, WHEN T05 is evaluated, THEN system approval is refused.

## Verification gate

Class 5 coverage of the T05 AUTO precondition.
