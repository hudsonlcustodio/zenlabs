## User story

COMO security reviewer, QUERO client-derived text carried as data and never as instruction, PARA a document cannot rewrite the system's instructions.

## Context

`intelligence-engine.md` §4 and §4.1. RISK-06 is High precisely because knowledge sources are client-supplied. The boundary is structural: the builder is the only path that assembles a prompt.

## Acceptance criteria

- **AC-1** The builder is the only code path that assembles a prompt; direct string assembly elsewhere is rejected.
- **AC-2** Instruction and data regions are structurally separate, not separated by delimiters that content could forge.
- **AC-3** Retrieved chunks enter only the data region, tagged with their provenance.
- **AC-4** Context assembly is deterministic given the same inputs, so a generation can be explained.
- **AC-5** Context size limits are enforced from configuration and truncation is recorded rather than silent.

## BDD examples

- EX-P10-01 GIVEN a knowledge chunk containing instruction-shaped text, WHEN a prompt is assembled, THEN that text appears only in the data region and never as an instruction.
