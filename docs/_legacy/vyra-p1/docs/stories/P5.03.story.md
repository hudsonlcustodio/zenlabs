## User story

COMO content strategist, QUERO identity modelled as versioned elements, PARA brand, voice and behavioural rules can evolve without losing what produced past content.

## Context

FR-ID01 and `domain-model.md` §2: identity composes visual, voice, knowledge, brand and behavioural rules, each independently versioned. Module 4 carries that invariant.

## Acceptance criteria

- **AC-1** Each identity element is versioned independently.
- **AC-2** A generation records which element versions were active when it ran.
- **AC-3** Superseding an element version never rewrites or deletes the prior one.
- **AC-4** The composite identity resolves to a coherent set of active element versions at any instant.

## BDD examples

- EX-P5-03a GIVEN a brand rule updated after a script was generated, WHEN the script's provenance is read, THEN it names the version that actually produced it.

## Verification gate

Integration tests asserting version resolution and provenance.
