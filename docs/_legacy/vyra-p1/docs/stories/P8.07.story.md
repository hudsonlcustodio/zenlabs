## User story

COMO publisher, QUERO the scheduling and publication transitions implemented exactly, PARA publication state is as rigorous as generation state.

## Context

`workflows-state-machines.md` T17-T23. T21 cancels, T22 blocks and explicitly excludes `ingestion_failed`, T23 archives after retention.

## Acceptance criteria

- **AC-1** T17 requires a connected channel and a future `scheduledFor`, keyed on `contentItemId+channelId`.
- **AC-2** T18 to T20 implement dispatch, success with `externalPostId`, and terminal rejection with its error class.
- **AC-3** T21 releases reservations on cancellation for any state that is not `PUBLISHED`.
- **AC-4** T22 freezes the item and releases held reservations only, never reversing a commit, and explicitly excludes `ingestion_failed` which is reached only via T11b.
- **AC-5** T23 archives after the retention window elapses.
