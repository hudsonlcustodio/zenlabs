# Story P4.07 — FF-02 and FF-03 provider isolation checks

- **Story ID**: `P4.07`

## User story

COMO architect, QUERO provider SDKs and vendor types barred from the domain, PARA vendor substitution stays a configuration change rather than a rewrite.

## Context

FF-02 forbids provider SDK imports in domain or application layers; FF-03 forbids provider-specific types in the domain.

## Acceptance criteria

- **AC-1** FF-02 fails when a domain or application file imports a provider SDK, naming the file.
- **AC-2** FF-03 fails when a domain type references a provider-specific shape.
- **AC-3** The checks enumerate SDK packages from the dependency manifest rather than from a hand-written list.
- **AC-4** Both run in the fitness-function stage from P1.06.

## BDD examples

- EX-P4-01 GIVEN a file under `domain/`, WHEN it imports a provider SDK, THEN FF-02 fails naming the file.

## Verification gate

FF-02 and FF-03 green on the clean tree and red on seeded violations.
