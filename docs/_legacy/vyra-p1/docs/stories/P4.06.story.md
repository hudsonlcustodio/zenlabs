# Story P4.06 — PROVIDER_MODE switching

## User story

COMO platform operator, QUERO provider selection controlled by configuration, PARA no environment can accidentally reach a live provider.

## Context

`provider-architecture.md` §9 and NFR-12. The key was reserved in P1.05; this story gives it meaning.

## Acceptance criteria

- **AC-1** `PROVIDER_MODE` selects mock or live per provider and is validated at boot.
- **AC-2** Live mode requires credentials to be present, and their absence fails boot rather than falling back silently.
- **AC-3** The default in development and CI is mock, and overriding it requires an explicit setting.

## BDD examples

- EX-P4-03 GIVEN `PROVIDER_MODE` set to mock, WHEN the full suite runs, THEN no outbound call to a provider host occurs.

## Verification gate

Integration test asserts mock selection and fail-fast on missing live credentials.
