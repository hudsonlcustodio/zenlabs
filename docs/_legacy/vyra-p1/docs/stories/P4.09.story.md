# Story P4.09 — FF-08 no billable provider call in CI

- **Story ID**: `P4.09`

## User story

COMO platform operator, QUERO CI structurally incapable of spending provider credit, PARA a test run can never produce an invoice.

## Context

NFR-13 and FF-08. `testing-strategy.md` §3 states no standard suite consumes real provider credit.

## Acceptance criteria

- **AC-1** The check fails if any standard suite is configured to run against live provider mode.
- **AC-2** Outbound calls to provider hosts during the standard suite fail the run rather than succeeding quietly.
- **AC-3** The check is part of the pipeline, not a documented convention.

## BDD examples

- EX-P4-03 GIVEN the standard suite, WHEN it executes, THEN no outbound call to a provider host occurs.

## Verification gate

FF-08 green; a seeded live-mode suite turns it red.

## Out of scope

- Pre-launch verification against live providers, which is a gated manual activity.
