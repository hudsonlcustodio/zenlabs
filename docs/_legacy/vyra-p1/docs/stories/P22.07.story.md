## User story

COMO publicador, QUERO ver o que vai sair, o que está saindo e o que falhou com a saúde das conexões ao lado, PARA que uma restrição de plataforma seja conhecida antes da publicação e nunca adivinhada.

## Context

`FR-S08` covers publication management. Four external gates live here: `GATE-TT01` (TikTok audit — posts restricted to `SELF_ONLY`), `GATE-TT02` (AIGC disclosure mechanism unconfirmed — publication blocked rather than guessed, `FF-15`), `GATE-MT01` (Meta App Review) and `GATE-MT02` (scope names). `VYRA_PRODUCT_EXPERIENCE.md` §32.13 requires each of them to be visible, stated and never silently worked around.

## Acceptance criteria

- **AC-1** The `L-board` of §32.13 renders four lanes — Scheduled, Publishing, Published, Failed — with a connection health strip above showing each channel's state and token expiry.
- **AC-2** A publishing item carries the `glow-live` indicator (capped at one per region) and shows elapsed time; a published item links to the external post.
- **AC-3** A failed publication shows its error class and the retry path that is legal for its state (T20 allows revert to `READY` on operator action); retry is idempotent on the publication id.
- **AC-4** **`GATE-TT02` blocks rather than guesses**: where the AIGC disclosure mechanism is unconfirmed, publication is blocked with the reason stated on the card and in the drawer. No wire mapping is inferred (`FF-15`).
- **AC-5** **`GATE-TT01` is stated in both directions**: a TikTok item shows the `SELF_ONLY` restriction before publication and after it, so nobody discovers the restriction from the reach numbers.
- **AC-6** Connection problems are actionable: `connection_invalid`, expired and expiring tokens each render with a reconnect action; `GATE-MT02` scope mismatches name the missing scope resolved from configuration, and `GATE-MT01` renders as a pending app review rather than as a failure.
- **AC-7** No token value is ever displayed, copyable or partially revealed; only state and expiry render (`FF-10`).

## BDD examples

- EX-P22-04 GIVEN a TikTok item whose AIGC disclosure mechanism is unconfirmed, WHEN publication is attempted, THEN it is blocked with the reason stated rather than guessed.
- EX-P22-19 GIVEN a TikTok item under `GATE-TT01`, WHEN it renders before and after publication, THEN the `SELF_ONLY` restriction is stated in both.
- EX-P22-20 GIVEN any connection row, WHEN it renders, THEN no token value appears.

## Verification gate

Four lanes render with a connection health strip; publishing shows live state and elapsed time; failures show error class and a legal, idempotent retry; `GATE-TT02` blocks with a stated reason; `GATE-TT01` restriction is stated before and after publication; connection problems offer reconnection and name missing scopes; the token-display assertion proves no token value renders.
