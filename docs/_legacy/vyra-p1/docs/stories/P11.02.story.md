# Story P11.02 — Audio ingestion to S3

## User story

COMO platform operator, QUERO synthesised audio stored in VYRA-owned private storage, PARA the render step is driven by an asset we control.

## Context

ADR-0016 fixes media storage; NFR-11 forbids local disk. T09 requires the audio asset ingested to S3 before `RENDER_QUEUED`.

## Acceptance criteria

- **AC-1** Audio is streamed to private S3 without an intermediate local file (FF-21).
- **AC-2** The object is private by default; no public read is configured (module 12 invariant).
- **AC-3** A checksum is recorded so integrity can be verified before handoff.
- **AC-4** T09's precondition consults this ingestion result rather than assuming success.

## BDD examples

- EX-P11-03 GIVEN audio synthesis, WHEN the result is stored, THEN nothing is written to local disk.

## Verification gate

Integration tests plus FF-21.
