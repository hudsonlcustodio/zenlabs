## User story

COMO frontend engineer, QUERO um player próprio que só reproduza URLs assinadas e carregue a divulgação de IA de forma não suprimível, PARA que entrega de mídia e conformidade sejam propriedades do componente e não da tela.

## Context

`security-architecture.md` §6 fixes short-TTL CloudFront signed URLs as the only delivery path, and `aws-topology.md` §5 makes every object private. `FF-15` makes AI disclosure non-suppressible. `VYRA_PRODUCT_EXPERIENCE.md` §24 fixes the player anatomy, the keyboard map and the comparison modes that video approval and QA need.

## Acceptance criteria

- **AC-1** A custom control layer over the native `<video>` element — no third-party player dependency. Frame at `radius-2xl`, `bg-sunken` letterbox, controls over the sanctioned media scrim gradient (§5.6), auto-hiding after 2.5s **only while playing**.
- **AC-2** The primitive accepts a signed URL and **refuses to render a bare bucket or public object URL**, failing loudly in development and rendering the error state in production. No `crossorigin` attribute points at a public object.
- **AC-3** Signed-URL lifecycle: the primitive requests a refresh through an injected callback at a configured margin before expiry and swaps the source without interrupting playback. A refresh failure surfaces as a region error with a retry, never as a silent stall.
- **AC-4** AI disclosure is structural: the disclosure affordance is rendered by the primitive itself, is not a prop the caller may omit or hide, and no tenant setting removes it (`FF-15`).
- **AC-5** The full keyboard map of §24.3 is implemented, none of it fires while focus is inside a text field, and a `?` overlay lists every shortcut.
- **AC-6** Poster handling: the first ingested frame when available, otherwise a `bg-sunken` frame carrying the content title — never a spinner over black. Captions render from a track when one exists, styled with product tokens.
- **AC-7** A side-by-side comparison mode renders two players with a synchronised scrubber on one shared timeline, and a timestamp-annotation API marks the scrubber and reports marks to the caller (used by QA in `P22.06`).

## BDD examples

- EX-P19-05 GIVEN a signed URL that expires during playback, WHEN the margin is reached, THEN the URL is refreshed transparently and playback does not stop.
- EX-P19-17 GIVEN a bare S3 URL, WHEN it is passed to the player, THEN the player refuses it and renders the error state.
- EX-P19-18 GIVEN any caller, WHEN it attempts to hide the AI disclosure, THEN no such prop exists.

## Verification gate

Playback works from a signed URL and refuses a non-signed one; transparent refresh asserted with an expiring fixture; the disclosure is unremovable through the public API; the full keyboard map is asserted including the text-field suppression; poster fallback and captions render; side-by-side scrub synchronisation asserted; axe zero serious/critical.
