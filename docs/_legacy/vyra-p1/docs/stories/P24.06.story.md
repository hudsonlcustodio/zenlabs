## User story

COMO implementing agent, QUERO um orçamento de performance por tela medido até a primeira região significativa, PARA que `NFR-03` seja um portão de CI e não uma medição tardia em staging.

## Context

`NFR-03` sets critical screen load below 3s and `scalability-gates.md` §1 treats ≥ 3s as an investigation trigger. `P16.09` measures end-to-end against staging at wave 13 — far too late to be the only signal. `VYRA_PRODUCT_EXPERIENCE.md` §18.3 defines what is being measured: the streaming model means the budget applies to the **first meaningful region** (`ASM-P24-02`).

## Acceptance criteria

- **AC-1** A per-screen client budget is declared as configuration with recorded initial values derived from `NFR-03` (`OQ-P24-01`), and the critical-screen set is named explicitly rather than implied.
- **AC-2** Each screen is measured under modelled conditions — throttled CPU and network, cold cache — to the first meaningful region as defined by §18.3, and fails above its budget naming the screen and the measured value.
- **AC-3** A **bundle budget** per route group is asserted, proving the ADR-0035 consequence that a Portal user never downloads the Studio script editor: the chart, grid, editor, player and drag families are route-level dynamic imports and their absence from other routes is asserted.
- **AC-4** Font loading contributes no render-blocking third-party request (`P18.03` AC-2 re-asserted at screen level), and no screen introduces one.
- **AC-5** A budget regression fails CI; tightening a budget is a deliberate configuration change with its own review.

## BDD examples

- EX-P24-05 GIVEN a critical screen, WHEN it loads under the modelled conditions, THEN the first meaningful region paints within the recorded budget.
- EX-P24-14 GIVEN a Portal route, WHEN its bundle is analysed, THEN the script-editor family is absent.

## Verification gate

Per-screen budgets declared with the critical set named; each screen measured to first meaningful region under modelled conditions and within budget; per-route-group bundle budgets asserted with the five heavy families absent from routes that do not use them; zero render-blocking third-party requests; a seeded regression fails CI.
