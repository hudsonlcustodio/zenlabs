## User story

COMO content strategist, QUERO generated output validated before it is presented, PARA a malformed or empty generation never reaches a human as if it were finished.

## Context

`intelligence-engine.md` §6. T04 requires the validator to have passed before a script is presented for review.

## Acceptance criteria

- **AC-1** Validation checks structure, required sections and length bounds per task type.
- **AC-2** A failed validation prevents T04 and routes to retry or failure per the transition's declared policy.
- **AC-3** Validation results are recorded on the generation so repeated failures are diagnosable.
- **AC-4** Validation rules are configuration-driven rather than hard-coded per template.

## BDD examples

- EX-P10-05 GIVEN an output failing validation, WHEN T04 is evaluated, THEN the script is not presented for review.
