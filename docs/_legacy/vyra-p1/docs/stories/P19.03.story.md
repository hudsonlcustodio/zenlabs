## User story

COMO frontend engineer, QUERO um data grid próprio com ordenação, filtro, controle de colunas, fixação e seleção, PARA que Studio e Control tenham densidade profissional sem herdar a aparência de uma biblioteca.

## Context

`ADR-0035` selects TanStack Table **headless** — it contributes no markup and no style, which is exactly why it can be wrapped without importing a foreign visual language. `VYRA_PRODUCT_EXPERIENCE.md` §14.3 fixes the interaction table and §14.2 the anatomy that `P18.15` already established for simple tables.

## Acceptance criteria

- **AC-1** A data-grid primitive builds on the `P18.15` table anatomy and adds: sortable headers, filter chips, column show/hide and reorder, column pinning (first column and actions pinned by default, user may pin up to three), row selection with `Shift+Click` ranges, and a docked bulk-action bar.
- **AC-2** The boundary holds: a direct import of TanStack Table outside `packages/ui` fails the boundary lint naming the file. No TanStack type appears in the wrapper's public API.
- **AC-3** Sort, filter and column state are reflected in the URL so a grid view is linkable and survives refresh; column visibility and pinning persist per user per grid.
- **AC-4** The header checkbox selects **the loaded page only** and says so in its label, because cursor pagination means the total set is not loaded. Selecting across pages is not expressible.
- **AC-5** The bulk-action bar states the selected count and offers only actions valid for **every** selected row; an action valid for a subset is absent, not disabled-with-a-tooltip.
- **AC-6** Row interaction follows §14.3: click opens the drawer, `Cmd/Ctrl+Click` opens the full page, `Enter` on a focused row opens the drawer, and the primary row action is reachable by keyboard regardless of hover.
- **AC-7** A grid-local density toggle maps to `--vyra-row-h` and `--vyra-row-h-compact` without a component fork.

## BDD examples

- EX-P19-13 GIVEN a screen importing TanStack Table directly, WHEN the boundary lint runs, THEN it fails naming the file.
- EX-P19-14 GIVEN a header checkbox is used, WHEN rows are selected, THEN only the loaded page is selected and the label says so.
- EX-P19-15 GIVEN a selection whose rows do not all permit an action, WHEN the bulk bar renders, THEN that action is absent.

## Verification gate

Sorting, filtering, column control, pinning, selection and bulk actions work with VYRA-shaped props; the boundary lint turns red on a seeded direct import; URL round-trip for sort/filter/columns asserted; page-only selection enforced; bulk actions restricted to universally valid ones; keyboard row interaction asserted; axe zero serious/critical.
