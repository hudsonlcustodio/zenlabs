## User story

COMO cliente, QUERO ver o desempenho do que foi publicado sabendo exatamente quando o dado foi coletado, PARA que eu confie no número e entenda por que não existe um botão de atualizar.

## Context

`FR-P08` asks for performance metrics per published item and `FR-PF05` plus `FF-16` guarantee the read path never calls a provider — opening a dashboard makes zero provider calls. `VYRA_PRODUCT_EXPERIENCE.md` §29.1 draws the consequence: there is no refresh control because none can exist, so the snapshot's age must be visible instead.

## Acceptance criteria

- **AC-1** The screen renders per §31.11: period and channel controls, a KPI row with deltas against the previous equal period, a per-channel trend chart, a per-item table and an item drawer with per-collection-bucket detail.
- **AC-2** **Zero provider calls**: opening the screen, changing the period and changing the channel filter each record zero provider calls against the mock (`FF-16`, `EX-P15-04`).
- **AC-3** No refresh-from-platform affordance exists anywhere on the screen; instead every chart and KPI carries the `Collected {relative}` stamp from `P19.02` AC-2 with the absolute time and bucket in its tooltip.
- **AC-4** Gaps render as gaps: a missing bucket is a discontinuity in the line and a hatched cell in the table, never zero and never interpolated (`performance.md` §5, `P14.05`).
- **AC-5** Any cross-platform aggregate is labelled `indicative` with an explanation that platform metric definitions differ (`ASM-PF01`); per-platform is the default view.
- **AC-6** State coverage is complete and distinct: never published (`first-run`), no publications in the period (`filtered`), collection pending for the period (`absent-by-design` inside the chart frame, naming the next window), and per-region error with retry.
- **AC-7** Below `md` the trend shows one channel at a time switched by chips rather than a five-line chart, and the table becomes stacked object rows.

## BDD examples

- EX-P15-04 GIVEN the performance screen is opened, WHEN it renders, THEN zero provider calls are recorded against the mock.
- EX-P21-26 GIVEN a period with a missing collection bucket, WHEN the trend renders, THEN the line shows a discontinuity and the table cell is hatched.
- EX-P21-27 GIVEN any performance region, WHEN it renders, THEN no refresh-from-platform control exists.

## Verification gate

FF-16 green with zero provider calls on open and on every filter change; no refresh affordance exists; the collected-at stamp is present on every chart and KPI; gaps render as discontinuities and hatched cells; aggregates are labelled indicative; the four states are distinct and correct; the mobile single-channel trend renders below `md`.
