# Story P20.03 — Command palette with an authorized action corpus

## User story

COMO operador, QUERO uma paleta de comandos que só ofereça o que eu posso executar, PARA que velocidade não vire uma superfície de descoberta de ações proibidas.

## Context

`VYRA_PRODUCT_EXPERIENCE.md` §3.3 makes the palette the operator's real entry point on Studio and Control. It is also the fastest way to leak an unauthorized action, because it is a flat list of everything — so its corpus is derived from the same manifest as the rail and is matrix-tested against every role.

## Acceptance criteria

- **AC-1** `⌘K` / `Ctrl+K` opens the palette from anywhere except inside a text field, using the `P18.11` overlay container with its focus trap and focus return.
- **AC-2** Four scopes exist: *Go to* (navigation), *Find content*, *Find client* (Studio and Control only) and *Action*. Results are grouped by scope with keyboard navigation across groups.
- **AC-3** The action corpus is derived from the **same route manifest** as the rail. A matrix test compares the palette corpus with the manifest for every role and fails on any excess entry; an action the session cannot execute does not appear, disabled or otherwise.
- **AC-4** The Portal ships the palette with the reduced corpus of §3.3 — navigation plus the tenant's own content items — resolving `OQ-P20-02` at the default.
- **AC-5** Search is debounced, cancellable, announces its result count through a live region, and renders the `filtered` empty state from `P18.14` when nothing matches. Recent selections persist per user per surface.

## BDD examples

- EX-P20-02 GIVEN the command palette, WHEN its corpus is compared with the route manifest for the session's role, THEN it contains no action the session cannot execute.
- EX-P20-11 GIVEN focus inside a text field, WHEN the user types the palette shortcut, THEN the palette does not open.

## Verification gate

The palette opens and closes with correct focus behaviour; the corpus-vs-manifest matrix test is green for every role with zero excess; the Portal corpus is the reduced set; search announces its result count and renders the filtered empty state; the shortcut does not fire inside text fields.
