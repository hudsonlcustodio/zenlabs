## User story

COMO frontend engineer, QUERO o shell da aplicação como uma composição única para as três superfícies, PARA que a moldura de toda tela esteja pronta e testada antes da primeira tela existir.

## Context

`ADR-0003` fixes one Next.js App Router application hosting Portal, Studio and Control. `VYRA_PRODUCT_EXPERIENCE.md` §3.1 fixes the shell anatomy — 56px topbar, 248/64px rail, content on `bg-base`, right drawer region — and §18.3 requires the shell to paint before its data regions resolve, which is how `NFR-03` is served structurally rather than by optimisation.

## Acceptance criteria

- **AC-1** One shell composition serves all three surfaces, parameterised by surface label, rail item set, density and chrome. A per-surface shell fork is a defect; the composition test asserts one implementation.
- **AC-2** Regions match §3.1: topbar at 56px on `surface-1` with a `border-subtle` bottom; rail at 248px expanded and 64px collapsed on `surface-1`; content on `bg-base` using the 12-column grid from `P18.04`; a right drawer region that hosts exactly one drawer at a time (`P18.11` AC-2).
- **AC-3** Landmark structure is correct and complete: `banner`, `navigation`, `main`, `complementary` where a meta rail exists, plus a skip link to `main` as the first focusable element (§23.2).
- **AC-4** The shell streams: topbar, rail, page header and static structure paint first, and each data region resolves inside its own boundary with its own `P18.14` skeleton. A blocking full-page load is a defect.
- **AC-5** A route change moves focus to the page `<h1>` and announces the new title through the live-region service from `P18.12`.
- **AC-6** Rail collapse state persists per user per surface; the shell renders correctly on first paint with no collapse flash, and the persisted value is a client preference (`ASM-P20-03`).

## BDD examples

- EX-P20-04 GIVEN a route change, WHEN it completes, THEN focus moves to the page `<h1>` and the new title is announced.
- EX-P20-09 GIVEN a page whose data is slow, WHEN it loads, THEN the shell and page header are painted before the data regions resolve.

## Verification gate

One shell implementation serves three surfaces; region geometry and landmarks asserted; the skip link is the first focusable element; streaming order asserted with a delayed-data fixture; route-change focus and announcement asserted; rail collapse persists without a first-paint flash; axe zero serious/critical.
