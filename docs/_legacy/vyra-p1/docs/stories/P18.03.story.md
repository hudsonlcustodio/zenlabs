## User story

COMO frontend engineer, QUERO a escala tipográfica completa com fontes variáveis auto-hospedadas e uma camada de strings, PARA que a hierarquia editorial seja um token e nenhum texto de interface seja um literal espalhado.

## Context

`VYRA_PRODUCT_EXPERIENCE.md` §6 fixes one family carrying the whole product, with editorial force coming from scale, weight and tracking contrast. Self-hosting is not a preference: an external font host is a third-party request from a page that renders tenant data, and it is render-blocking against `NFR-03`.

## Acceptance criteria

- **AC-1** Every type role in §6.2 exists as a token and as a component-level utility: `display-2xl` through `mono-sm`, each carrying its size, line-height, tracking and weight as one indivisible unit. A component setting size without its matching line-height and tracking fails the lint.
- **AC-2** Both faces are self-hosted as variable fonts through `next/font/local`, subset, preloaded and `font-display: swap`-free — no external font request is made by any page, asserted by a network test.
- **AC-3** **PD-03 (numbers are the hero)** is enforced typographically: tabular figures are required on every `metric-*` and `mono-*` role and on numeric table cells, asserted by a computed-style test rather than by convention.
- **AC-4** A string layer holds every user-visible string with a locale key. pt-BR is authored; the layer supports a second locale from day one (`OQ-PX-01`, `ASM-P18-03`). A user-visible literal in a component fails the string-source lint.
- **AC-5** Layout tolerates pt-BR length: every label region declares a truncation strategy from §14.5, and a length-stress test renders each primitive with a string 30% longer than its pt-BR value without overflow or overlap.

## BDD examples

- EX-P18-12 GIVEN a page render, WHEN network requests are inspected, THEN no request to an external font host occurs.
- EX-P18-13 GIVEN a component with a hard-coded user-visible string, WHEN the string-source lint runs, THEN it fails naming the string.
- EX-P18-14 GIVEN a label rendered with a 30%-longer string, WHEN the stress test runs, THEN it truncates by its declared strategy without overlapping a neighbour.

## Verification gate

All type roles exported and lint-enforced as indivisible units; zero external font requests; tabular figures asserted on every numeric role; the string-source lint turns red on a seeded literal; the length-stress test passes for every primitive.
