## User story

COMO portal user, QUERO to upload my material without thinking about processing, PARA my institutional knowledge informs every script.

## Context

FR-KN01 lists documents, PDFs, presentations, FAQs, methodologies, offers, links, text, audio and prior content. `knowledge-engine.md` §2 fixes accepted inputs. NFR-11 forbids persisting media on local disk.

## Acceptance criteria

- **AC-1** Uploads land in private S3 storage; nothing is written to local disk (NFR-11).
- **AC-2** A `knowledge_source` row records origin, declared type, size, checksum and processing status.
- **AC-3** Accepted input types follow `knowledge-engine.md` §2 exactly (ASM-P9-01).
- **AC-4** Ingestion is enqueued through the P7 outbox rather than executed inline.

## BDD examples

- EX-P9-01a GIVEN an upload of an accepted type, WHEN it completes, THEN the source is recorded as pending processing and a job is enqueued.
