## Acceptance criteria

- **AC-1** No code path triggers a render submission in response to an ingestion failure.
- **AC-2** No code path releases or reverses a commit in response to an ingestion failure.
- **AC-3** The check fails when either path is introduced, naming it.
- **AC-4** The forced-ingestion-failure fixture from P4.05 drives the corresponding test.
