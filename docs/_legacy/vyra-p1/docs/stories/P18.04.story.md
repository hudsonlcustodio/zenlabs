## User story

COMO frontend engineer, QUERO escala de espaçamento, grid, breakpoints e modos de densidade como tokens, PARA que Portal confortável e Studio denso sejam o mesmo componente com outro conjunto de tokens.

## Context

`VYRA_PRODUCT_EXPERIENCE.md` §7 and §8 fix a 4px base scale, three vertical-rhythm gaps, seven breakpoints, a 12-column grid and two density modes. §7.4 makes density a token override applied at the surface root — never a component fork, which is how design systems rot into two design systems.

## Acceptance criteria

- **AC-1** The spacing scale of §7.1 exists as tokens and is the only source of margin, padding and gap. The token lint from `P18.01` AC-4 rejects any off-scale length.
- **AC-2** The seven breakpoints of §8.1 are declared once and consumed by Tailwind, by the density system and by the responsive tests; a component declaring a raw media query fails the lint.
- **AC-3** A 12-column grid primitive implements §8.2 — 24px gutter at `≥ lg`, 16px below, 1440px content max, 760px reading-column max, left-aligned — and the seven standard layouts of §8.3 exist as composable layout components (`L-dashboard`, `L-collection`, `L-object`, `L-workspace`, `L-focus`, `L-board`, `L-calendar`).
- **AC-4** **PD-08 (density follows the operator)** is implemented as data: two density modes exist as a root-level token override (`--vyra-control-h`, `--vyra-row-h`, `--vyra-row-h-compact`, `--vyra-card-pad`, `--vyra-stack-gap`, `--vyra-font-body`). A component branching on density in code fails the lint; density is data.
- **AC-5** Touch targets remain ≥ 24×24 CSS px in every density mode and ≥ 44×44 on coarse pointers, asserted for every interactive primitive in both modes (§23.4, WCAG 2.2 SC 2.5.8).
- **AC-6** The layout invariants of §8.4 are asserted: no page body scrolls horizontally at any of the seven breakpoints, and a wide region scrolls inside its own container with a visible edge affordance.

## BDD examples

- EX-P18-15 GIVEN dense mode, WHEN an interactive primitive is measured on a coarse pointer, THEN its target is at least 44×44.
- EX-P18-16 GIVEN any standard layout at 320px width, WHEN it renders, THEN the page body does not scroll horizontally.

## Verification gate

The spacing scale is the only source of lengths and the lint proves it; the seven layouts render at all seven breakpoints with no horizontal page scroll; both density modes are token-only with zero code branching; the target-size assertion passes in both modes.
