## User story

COMO portal user, QUERO to view my video without the file being publicly reachable, PARA client media is private by default rather than by obscurity.

## Context

`security-architecture.md` §6 and ADR-0016. Module 12's invariant is that media is private by default.

## Acceptance criteria

- **AC-1** `media_asset` records the S3 key, checksum, duration and its owning attempt, tenant-scoped.
- **AC-2** Access is exclusively by expiring signed URL; no object is publicly readable.
- **AC-3** Signed URL expiry comes from configuration and is asserted by a class 13 test.
- **AC-4** Issuing a signed URL is authorized by the P3 guards, so an unauthorised actor cannot obtain one.

## BDD examples

- EX-P11-05 GIVEN an approved video, WHEN it is accessed, THEN access is by expiring signed URL rather than a public object.

## Verification gate

Class 13 signed-URL expiry tests green.
