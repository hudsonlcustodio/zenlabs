## User story

COMO implementing agent, QUERO o servidor de banco provisionado com os dois papéis que a arquitetura exige e recuperação testada, PARA que a isolação por RLS não dependa de um papel privilegiado demais e um restore não seja uma suposição.

## Context

`aws-topology.md` §4 fixes RDS PostgreSQL with `pgvector`, Single-AZ at MVP, automated backups with PITR, and **two roles**: `vyra_migrator` (DDL owner) and `vyra_app` (DML only, no `BYPASSRLS`, not table owner). That role split is what makes `FF-01`'s RLS guarantee real — an application connecting as the table owner would bypass every policy. `P2.02` defines the role split in migration tooling; this story creates the server and the roles it operates on.

## Acceptance criteria

- **AC-1** One RDS PostgreSQL instance per environment, Single-AZ, in `sa-east-1`, not publicly accessible, reachable only from the environment's compute security group.
- **AC-2** The `pgvector` extension is available and its version is pinned, so an embedding-dimension change follows the expand/contract procedure in `migrations.md` §4 rather than an implicit upgrade.
- **AC-3** `vyra_migrator` and `vyra_app` exist with the exact privilege split `aws-topology.md` §4 fixes. An automated assertion proves `vyra_app` has **no** `BYPASSRLS`, is **not** the owner of any table, and cannot execute DDL.
- **AC-4** Automated backups are enabled with point-in-time recovery; the retention window is configuration per environment with a documented default, closing `OQ-P17-02` at the value the owner records.
- **AC-5** Encryption at rest with KMS is enabled and TLS is required for connections; a non-TLS connection attempt is rejected.
- **AC-6** A **restore drill** is executed as part of this story against a non-production environment and its result recorded, so `aws-topology.md` §4's "restore drills are a scheduled operational exercise, not an assumption" is true from the first day rather than from `P16`.

## BDD examples

- EX-P17-13 GIVEN the `vyra_app` role, WHEN its privileges are enumerated, THEN it holds no `BYPASSRLS` and owns no table.
- EX-P17-14 GIVEN a connection attempt without TLS, WHEN it reaches the instance, THEN it is rejected.
- EX-P17-15 GIVEN a point-in-time restore to a timestamp before a seeded destructive change, WHEN the drill runs, THEN the restored instance contains the pre-change state.

## Verification gate

The instance exists per environment and is not publicly accessible; the role-privilege assertion is green and turns red on a seeded grant of `BYPASSRLS`; `pgvector` is available at the pinned version; a non-TLS connection is rejected; the restore drill result is recorded with its timestamp and outcome.
