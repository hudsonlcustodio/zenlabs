## User story

COMO implementing agent, QUERO a deterministic mock for every port, PARA development and CI proceed while GATE-HG01 and GATE-EL01 remain unsigned.

## Context

`provider-architecture.md` §9 and `testing-strategy.md` §3. Fixtures are recorded shapes, never invented endpoints; where a contract is gated the fixture is marked provisional and its adapter test is skipped with an explicit gate reference.

## Acceptance criteria

- **AC-1** Every port has a mock covering the success path.
- **AC-2** Every error class in the taxonomy has at least one failure fixture per port.
- **AC-3** Fixtures for gated contracts (GATE-HG04, GATE-TT02, GATE-MT02, GATE-COST01) are marked provisional and their tests skipped with the gate named, rather than asserting a guessed shape.
- **AC-4** Mocks are deterministic; the same input yields the same output across runs.
- **AC-5** The mock for a completed-but-unretrievable generation exists, because P11.10 depends on being able to force it.

## BDD examples

- EX-P4-05a GIVEN a provisional fixture, WHEN its adapter test runs, THEN it is skipped with the blocking gate named rather than asserting an invented shape.
