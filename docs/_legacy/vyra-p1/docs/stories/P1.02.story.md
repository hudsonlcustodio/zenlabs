## User story

COMO implementing agent, QUERO the seven packages to exist with their declared dependency direction, PARA the boundary rules in P1.03 have something concrete to constrain.

## Context

`architecture.md` §2.2 fixes `contracts`, `database`, `providers`, `security`, `observability`, `config`, `ui` and what each may depend on.

## Acceptance criteria

- **AC-1** All seven packages exist with build and typecheck wired.
- **AC-2** Each package declares its permitted dependencies exactly as tabulated in `architecture.md` §2.2.
- **AC-3** `packages/contracts` declares no runtime dependency that performs I/O.
- **AC-4** All five `apps/*` workspaces from `architecture.md` §2.1 exist as empty, buildable placeholders — `web`, `api`, `worker-ai`, `worker-media`, `worker-social` — so that no later story has to invent a process. Their contents are bootstrapped in `P1.08` and `P1.09`.

## BDD examples

- EX-P1-02a GIVEN `packages/contracts`, WHEN its dependency list is inspected, THEN it names no sibling package.
