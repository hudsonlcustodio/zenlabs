## User story

COMO usuário, QUERO um centro de notificações que diga exatamente o que precisa de mim, PARA que uma aprovação pendente nunca dependa de eu lembrar de olhar.

## Context

`ADR-0027` leaves `EmailProvider` unimplemented and `GATE-NOTIF01` open; in-app delivery ships first (`P16.06`). `VYRA_PRODUCT_EXPERIENCE.md` §3.4 fixes the three categories and the one copy constraint that keeps the gate honest: the UI must not imply an email was sent.

## Acceptance criteria

- **AC-1** A bell in the topbar shows unread state as a lime dot below one item and a count to `99+` above; the panel is a 400px right drawer, a bottom sheet below `md`.
- **AC-2** Notifications are grouped by day within three categories: **needs you** (approvals, consent, payment), **finished** (published, ready) and **attention** (blocked, failed). Category is derived from the notification type, never authored per message.
- **AC-3** Copy never states or implies email delivery. A copy lint rejects the words for *email*, *inbox* and *sent to you* in notification strings while `GATE-NOTIF01` is open, and the gate reference is recorded in the story's verification record.
- **AC-4** Mark-as-read and mark-all-read are available; read state is server-side so it is consistent across devices. Opening a notification navigates to its object and marks it read.
- **AC-5** The panel renders `absent-by-design` empty ("You're up to date"), loading and error states from `P18.14`, and announces new arrivals through the coalescing live region from `P18.12` AC-4.

## BDD examples

- EX-P20-03 GIVEN a notification, WHEN it renders, THEN it never states or implies that an email was sent.
- EX-P20-12 GIVEN five notifications arriving within ten seconds, WHEN they are announced, THEN at most one announcement is made.

## Verification gate

Bell and panel render with correct unread semantics; categories derive from type; the copy lint turns red on a seeded email reference; read state round-trips server-side; empty, loading and error states render; arrival announcements coalesce; axe zero serious/critical.
