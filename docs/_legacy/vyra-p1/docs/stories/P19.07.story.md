## User story

COMO frontend engineer, QUERO um editor cuja gramática não consiga expressar estilo visual, PARA que um roteiro permaneça um roteiro e nunca vire um documento formatado.

## Context

`ADR-0035` selects Tiptap over a **VYRA-owned document schema**. `VYRA_PRODUCT_EXPERIENCE.md` §25.2 fixes that schema deliberately narrow: six node types, three marks, and no font, colour, size, table, image or arbitrary HTML. That narrowness is the design decision — it is what keeps the editor a scripting tool and keeps voice synthesis able to read the document unambiguously.

## Acceptance criteria

- **AC-1** The document schema of §25.2 is implemented exactly: nodes `hook` (exactly one, first, ≤ 240 chars), `section`, `paragraph`, `direction`, `broll`, `cta` (at most one, last); marks `emphasis`, `pause`, `term`. Cardinality and ordering constraints are enforced by the schema, not by validation after the fact.
- **AC-2** Visual styling is **inexpressible**: no font, colour, size, alignment, table, image or arbitrary HTML node or mark exists. A paste containing styled HTML is reduced to schema-valid nodes and no style survives.
- **AC-3** The boundary holds: a direct import of Tiptap or ProseMirror outside `packages/ui` fails the boundary lint naming the file, and no Tiptap type appears in the wrapper's public API.
- **AC-4** `direction` and `broll` nodes are excluded from the spoken word count and are marked in the serialised output as non-spoken, so voice synthesis (`P11`) cannot read them by accident.
- **AC-5** Autosave fires on a 2s idle or on blur, exposes `Saved {relative}`, and a save failure retains the local buffer and surfaces an inline error — the buffer is never discarded.
- **AC-6** A read-only mode exists that renders the same document with the same typography and no editing affordance, because the Portal reads scripts and never edits them (§25.1).
- **AC-7** Full keyboard operation with no modifier-only path; a keyboard-reachable slash menu inserts nodes; every node type is announced by a screen reader; `Escape` always exits the canvas to the toolbar (§25.5).

## BDD examples

- EX-P19-06 GIVEN a paste containing styled HTML, WHEN it enters the script editor, THEN it is reduced to the VYRA schema and no style survives.
- EX-P19-21 GIVEN a document with two `hook` nodes, WHEN it is validated, THEN the schema rejects it.
- EX-P19-22 GIVEN a save failure, WHEN it occurs, THEN the local buffer is retained and an inline error is shown.

## Verification gate

The six nodes and three marks enforce cardinality and ordering at the schema level; a styled paste is reduced with no surviving style; the boundary lint turns red on a seeded direct Tiptap import; non-spoken nodes are excluded from the word count and marked in serialisation; autosave retains the buffer on failure; read-only mode renders identically without affordances; keyboard operation and screen-reader announcement asserted.
