## User story

COMO implementing agent, QUERO one package owning schema definition and data access primitives, PARA no application code ever opens its own connection or writes its own SQL dialect.

## Context

`architecture.md` §2.2 gives `packages/database` the Drizzle schema, migrations, RLS helpers and repository primitives, depending only on `contracts`. ADR-0008 fixes the ORM decision.

## Acceptance criteria

- **AC-1** Drizzle is configured and the package exposes the pool as the only sanctioned connection source.
- **AC-2** The package depends only on `packages/contracts`, verified by FF-04.
- **AC-3** An integration test proves connectivity against an ephemeral PostgreSQL instance.

## BDD examples

- EX-P2-01a GIVEN an application module, WHEN it imports a database driver directly, THEN FF-04 fails.
