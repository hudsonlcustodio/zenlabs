# Story P1.01 — Monorepo skeleton and workspace tooling

- **Story ID**: `P1.01`

## User story

COMO implementing agent, QUERO a single workspace with pinned toolchain and a uniform task interface, PARA every later epic is built and verified the same way.

## Context

ADR-0002 fixes a monorepo. `architecture.md` §2.1-§2.2 fixes five processes and seven packages. This story creates the shell only.

## Acceptance criteria

- **AC-1** `apps/` and `packages/` workspaces are declared and resolvable from the root.
- **AC-2** Node and package-manager versions are pinned in the repository, not assumed from the developer machine.
- **AC-3** `lint`, `typecheck`, `test` and `build` run recursively from the root with one command each.
- **AC-4** OQ-P1-01 is closed: the chosen workspace tool is recorded in the repository.

## BDD examples

- EX-P1-01a GIVEN a clean clone, WHEN the documented install command runs, THEN all workspaces resolve with no manual step.

## Verification gate

`pnpm lint typecheck test` exits zero on an empty workspace set.
