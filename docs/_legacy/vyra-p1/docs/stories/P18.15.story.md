## User story

COMO frontend engineer, QUERO uma tabela simples com semântica real e paginação por cursor, PARA que conteúdo tabular leve não precise do data grid completo e que nenhuma tela invente números de página que a API não tem.

## Context

`api-contracts.md` §1 fixes cursor-based pagination and forbids offset pagination on large sets. `VYRA_PRODUCT_EXPERIENCE.md` §14.2 fixes the table anatomy — no zebra striping, row dividers at `border-subtle`, right-aligned tabular numerics, `mono-md` identifiers — and §14.6 requires table states inside the table frame. Complex grids are `P19.03`; this is the light path.

## Acceptance criteria

- **AC-1** A table primitive renders real `<table>` semantics with a sticky header, `--vyra-row-h` row height, `border-subtle` dividers and **no zebra striping**. Numeric columns are right-aligned with tabular figures; identifier columns use `mono-md`.
- **AC-2** Cursor pagination controls exist in two forms — `Load more` for feeds and `Newer/Older` for ledgers — and **no page-number control is expressible**, because the API does not provide one. A total count renders only when the API returns one.
- **AC-3** Each column declares one truncation strategy from §14.5 — `truncate-end`, `truncate-middle`, `wrap-2` or `none` — and a truncated cell is always recoverable through a tooltip, a drawer or a copy action.
- **AC-4** Loading, empty, filtered-empty and error render **inside the table frame** with the header still visible, so column and filter context is never lost (§14.6).
- **AC-5** Keyboard navigation works: `↑ ↓ Home End PageUp PageDown` move the focused row, `Enter` opens the row, and the header is sortable by `Enter`/`Space` with sort state reflected in the URL.

## BDD examples

- EX-P18-34 GIVEN a table in its empty state, WHEN it renders, THEN the header remains visible and the empty state sits inside the frame.
- EX-P18-35 GIVEN a developer attempts to render page numbers, WHEN the component is compiled, THEN it is a type error.

## Verification gate

Real table semantics asserted; no page-number control exists in the API; per-column truncation strategies declared and recoverable; the four table states render inside the frame; keyboard row navigation and URL-reflected sort asserted; axe zero serious/critical.
