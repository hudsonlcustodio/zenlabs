## User story

COMO security reviewer, QUERO outbound fetches constrained by an allowlist and address checks, PARA link ingestion cannot be turned into a probe of our own network.

## Context

`security-architecture.md` §8 fixes egress control; FR-KN05 lists hostile URLs and SSRF among the required mitigations; FF-25 asserts the controls hold.

## Acceptance criteria

- **AC-1** Resolved addresses in private, loopback, link-local and metadata ranges are refused.
- **AC-2** Redirects are re-validated at each hop rather than trusted after the first check.
- **AC-3** Only schemes and ports on the allowlist are permitted, with the list in configuration.
- **AC-4** A refused fetch records a specific reason and does not leak internal responses to the user.

## BDD examples

- EX-P9-02 GIVEN a link pointing at a private network address, WHEN ingestion attempts to fetch it, THEN the egress control refuses.
