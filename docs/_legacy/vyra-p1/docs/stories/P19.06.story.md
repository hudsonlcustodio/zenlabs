## User story

COMO frontend engineer, QUERO um player de áudio com forma de onda pré-computada e primitivos de upload com estados explícitos, PARA que prévias de voz e ingestão de conhecimento sejam legíveis sem bloquear a página.

## Context

`VYRA_PRODUCT_EXPERIENCE.md` §24.6 and §24.7 fix the compact waveform player and the upload behaviour. The peak array is precomputed rather than decoded in the browser: decoding a voice sample client-side is slow, drains battery and — more importantly — would mean shipping the raw audio when a preview is all that is needed.

## Acceptance criteria

- **AC-1** A compact waveform player renders a 32px waveform from a **precomputed peak array supplied as data**; the primitive performs no client-side audio decoding.
- **AC-2** Played portion renders `accent-solid`, remainder `border-strong`, and the keyboard map is the §24.3 map minus the video-only keys.
- **AC-3** An upload primitive shows per-file progress, validates type and size **before transfer** and reports the reason on rejection, supports cancel per file, and never blocks the page.
- **AC-4** Upload state is explicit and distinct at every step — `uploaded`, `processing`, `indexed`, `partial`, `failed` — rendered through the `P18.13` status components rather than through local strings, so knowledge ingestion state means the same thing everywhere (§21.4).
- **AC-5** On coarse pointers the file picker accepts camera and document sources, and progress and cancel targets meet the 44×44 minimum.

## BDD examples

- EX-P19-19 GIVEN a file whose type is not permitted, WHEN it is selected, THEN it is rejected before any byte is transferred and the reason is stated.
- EX-P19-20 GIVEN an audio preview, WHEN it renders, THEN no client-side decode occurs and the waveform comes from the supplied peak array.

## Verification gate

Waveform renders from supplied peaks with no client decode; the keyboard map is asserted; pre-transfer validation rejects with a stated reason; the five upload states render through the status components; touch targets meet the minimum on coarse pointers.
