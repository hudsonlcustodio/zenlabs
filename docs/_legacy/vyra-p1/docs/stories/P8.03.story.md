## User story

COMO architect, QUERO transitions declared with all seven required fields, PARA FR-WF04 is structurally satisfied rather than reviewed by hand.

## Context

FR-WF04 and `workflows-state-machines.md` §1. Each transition defines authorized actor, preconditions, effects, emitted events, retry policy, compensation and idempotency.

## Acceptance criteria

- **AC-1** A transition declaration that omits any of the seven fields fails to compile or fails a schema check.
- **AC-2** The engine evaluates actor authorization before preconditions and both before effects.
- **AC-3** Effects and event writes occur in one transaction with the state change.
- **AC-4** Replay under the declared idempotency key is a no-op returning the original outcome.
- **AC-5** Retry and compensation are executed from the declaration rather than from call-site code.

## BDD examples

- EX-P8-02 GIVEN a transition triggered twice with the same idempotency key, WHEN both execute, THEN the second is a no-op.
- EX-P8-03 GIVEN an actor not listed for a transition, WHEN they trigger it, THEN it is denied rather than silently ignored.

## Verification gate

Class 5 suite green for the engine's four generic cases.
