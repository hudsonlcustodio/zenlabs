## User story

COMO platform operator, QUERO the commit written exactly once at T11, PARA FR-UC03 and FR-UC04 hold in the live path and not only in unit tests.

## Context

`usage-ledger.md` §4 fixes the lifecycle points; T11 commits and records provider cost; §2 restates the critical rule precisely.

## Acceptance criteria

- **AC-1** T11 commits usage with `producedDurationSeconds` and records the provider cost in the same transaction.
- **AC-2** The commit is idempotent on `attemptId`, so a duplicate webhook or a reconciler pass yields one entry.
- **AC-3** The minimum billable duration policy is applied from configuration rather than as a constant (FR-UC08).

## BDD examples
