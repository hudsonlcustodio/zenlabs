## User story

COMO frontend engineer, QUERO ícones consumidos apenas através de wrappers semânticos, PARA que trocar o conjunto de ícones seja uma mudança de um arquivo e que nenhum ícone carregue significado sem nome acessível.

## Context

`ADR-0003` fixes Lucide and `VYRA_PRODUCT_EXPERIENCE.md` §11 fixes four sizes, a 1.5 stroke, `currentColor` inheritance and — critically — that every icon usage is wrapped by a semantic component rather than imported into a screen.

## Acceptance criteria

- **AC-1** Four icon sizes (14, 16, 20, 24) exist as tokens with the prescribed stroke weights, and no other size is expressible.
- **AC-2** Icons inherit `currentColor`. A coloured icon is only possible through a semantic wrapper that carries meaning (status, channel); a colour applied to an icon in a screen fails the lint.
- **AC-3** A direct import of a Lucide icon outside `packages/ui` fails the boundary lint from `P1.03`, naming the file. Screens consume semantic wrappers only.
- **AC-4** Decorative icons are `aria-hidden`; an icon-only control carries an `aria-label` **and** a tooltip whose text is the same string, asserted by test.
- **AC-5** The five channel marks (Instagram, TikTok, YouTube, LinkedIn, Facebook) are the only third-party logos, render monochrome at rest, take their fixed `viz-*` colour only when identifying a data series, never render below 16px and never sit inside a filled chip (§11.4).
- **AC-6** The VYRA mark renders monochrome, is never animated, never gradient-filled and never paired with a wordmark inside product chrome (§11.5).

## BDD examples

- EX-P18-04 GIVEN an icon-only button without an accessible name, WHEN the a11y test runs, THEN it fails naming the component.
- EX-P18-20 GIVEN a screen importing a Lucide icon directly, WHEN the boundary lint runs, THEN it fails naming the file.

## Verification gate

Four sizes only; direct Lucide imports outside `packages/ui` fail the boundary lint; icon-only controls assert label-and-tooltip equality; the channel-mark constraints are asserted; the VYRA mark component exposes no animation or gradient prop.
