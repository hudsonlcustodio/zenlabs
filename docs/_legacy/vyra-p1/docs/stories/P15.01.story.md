# Story P15.01 — Design-system integration and per-surface theming in `apps/web`

## User story

COMO frontend engineer, QUERO que `apps/web` consuma o Design System VYRA como única fonte visual, PARA que nenhuma tela invente um valor e uma mudança de identidade continue sendo uma mudança de um pacote.

## Context

This story previously built the `packages/ui` primitives themselves. That work now belongs to epic `P18`, which builds the design system at **wave 2** — because `packages/ui` depends only on `packages/contracts` (`architecture.md` §2.2) and nothing about a token or a button needs the API, the database or the workflow engine. Building it early removes it from the wave-10 bottleneck and gives every surface a finished substrate.

What remains here is the integration: wiring `apps/web` to the design system so that the token layer, the theme, the fonts and the per-surface density are configured once, at the application root, and are impossible to bypass from a screen.

## Acceptance criteria

- **AC-1** `apps/web` consumes `packages/ui` as its only visual source. The Tailwind preset from `P18.01` AC-3 is applied at the application root, so no default Tailwind colour, spacing, radius or shadow utility exists to be typed inside a screen.
- **AC-2** Theme resolution is wired per `P18.02` AC-1: server-resolved from the user profile, falling back to `prefers-color-scheme`, falling back to carbon, with no theme flash on first paint.
- **AC-3** Per-surface density is applied at each route group's root through the `P18.04` AC-4 token override — comfortable for `(portal)`, dense for `(studio)` and `(control)` — with zero component-level branching.
- **AC-4** The self-hosted variable fonts from `P18.03` AC-2 are loaded through `next/font/local`; a network assertion proves no page issues an external font request.
- **AC-5** The token lint, the string-source lint and the boundary lint run over `apps/web` as they do over `packages/ui`: a raw colour, an off-scale length, a user-visible literal, or a direct import of Recharts, TanStack Table, dnd-kit, Tiptap or Motion fails CI naming the file.

## BDD examples

- EX-P15-10 GIVEN a screen using a raw hex colour, WHEN CI runs, THEN the token lint fails naming the file and the value.
- EX-P15-11 GIVEN a page render, WHEN network requests are inspected, THEN no external font request occurs.
- EX-P15-12 GIVEN a user with an explicit theme preference, WHEN the application first paints, THEN it paints in that theme with no flash.

## Verification gate

The Tailwind preset is applied at the root with no default scales reachable; theme resolves in the documented order with no flash; density is correct per route group and is token-only; zero external font requests; the token, string-source and boundary lints run over `apps/web` and each turns red on its own seeded violation.
