## User story

COMO architect, QUERO a check proving no approval setting can bypass QA, PARA FR-AP04 is enforced by the build rather than by review.

## Context

FF-33 requires that VYRA QA cannot be skipped by a client approval setting. `testing-strategy.md` §2.3a states the same as a highest-value test for both MANUAL and AUTO.

## Acceptance criteria

- **AC-1** For tenant policy AUTO and MANUAL alike, an item without a passing human `QARecord` can never reach `READY`.
- **AC-2** The check covers `SCHEDULED` and `PUBLISHED` as well, since those are downstream of `READY`.
- **AC-3** A code path that would allow the skip fails FF-33, naming the path.
- **AC-4** The check runs in the fitness-function stage from P1.06.

## BDD examples

- EX-P12-01 GIVEN a tenant with AUTO video approval and no human QA verdict, WHEN FF-33 runs, THEN it confirms READY is unreachable.

## Verification gate

FF-33 green on the clean tree and red on a seeded bypass.
