# Story P5.08 — FF-12 no bypass of provider voice verification

- **Story ID**: `P5.08`

## User story

COMO security reviewer, QUERO the verification path structurally unbypassable, PARA FR-ID06 is enforced rather than promised.

## Context

FF-12 requires that no mechanism bypasses provider voice verification. `prd.md` §9.2 notes verification is an ethical and legal safeguard.

## Acceptance criteria

- **AC-1** No code path sets a voice clone to verified or ready without a provider verification result.
- **AC-2** Test helpers that fabricate verification are confined to test scope and cannot be reached from production code.
- **AC-3** The check fails when a bypass is introduced, naming the path.

## BDD examples

- EX-P5-03 GIVEN a voice clone whose provider verification has not returned success, WHEN code attempts to mark it ready, THEN FF-12 fails on that path.

## Verification gate

FF-12 green on the clean tree and red on a seeded bypass.
