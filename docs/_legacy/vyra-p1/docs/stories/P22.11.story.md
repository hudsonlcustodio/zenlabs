## User story

COMO operador, QUERO que cada tela do Studio tenha seus estados projetados, incluindo a recusa em telas pequenas, PARA que nada no ambiente de trabalho pareça inacabado.

## Context

PD-09 applies to Studio as it does to the Portal, with one addition: §22.1 commits Studio only from `lg` upward, so the **refusal below `md` is itself a screen** and is conformance-tested like any other. This story is the coverage gate for the Studio route group.

## Acceptance criteria

- **AC-1** A coverage check enumerates every Studio blueprint in §32 and asserts each has an implemented loading, empty, error and denied state; a new Studio route without them fails CI naming the route.
- **AC-2** Empty-state kinds are asserted, not merely presence, and generic copy fails the copy lint.
- **AC-3** Error states carry the §20.2 anatomy at the correct scope with stable codes and correlation ids; Studio **may** name a provider where the operator needs it (unlike the Portal), but never renders raw vendor error text (`FF-20`).
- **AC-4** The sub-`md` designed refusal renders for every Studio route, states the reason, links to the Portal where the session has access, and passes the `P18.16` conformance harness like any other screen.
- **AC-5** The `md` degraded mode of §22.1 is implemented where declared: read plus single-object actions, boards and grids as lists, with the degradation stated rather than silent.

## BDD examples

- EX-P22-08 GIVEN Studio at 375px, WHEN any route renders, THEN the designed refusal appears and passes the conformance harness.
- EX-P22-27 GIVEN a Studio route added without an error state, WHEN CI runs, THEN the coverage check fails naming the route.
- EX-P22-28 GIVEN Studio at 768px, WHEN a board renders, THEN it degrades to a list and states the degradation.

## Verification gate

The blueprint coverage check is green across every §32 screen and turns red on a seeded missing state; empty-state kinds asserted; error scopes correct with no raw vendor text; the sub-`md` refusal renders on every route and passes the harness; the `md` degraded mode renders and states its degradation.
