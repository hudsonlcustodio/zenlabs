## User story

COMO security reviewer, QUERO authentication and sensitive endpoints rate-limited and lockable, PARA credential stuffing is expensive rather than free.

## Context

`security-architecture.md` §1.2 and `api-contracts.md` §8. Thresholds are configuration per ASM-MT01 reasoning: operational values are not architectural constants.

## Acceptance criteria

- **AC-1** Failed-attempt counters drive lockout with thresholds and windows from configuration.
- **AC-2** Rate limiting applies per identity and per source, so one does not defeat the other.
- **AC-3** A locked account produces a stable error code from `api-contracts.md` §1.1 that does not disclose whether the user exists.
- **AC-4** Lockout and unlock are audited.

## BDD examples

- EX-P3-03 GIVEN repeated failed logins beyond the threshold, WHEN another attempt is made, THEN it is locked out rather than evaluated.

## Verification gate

Class 13 security suite green for brute-force lockout.
