## User story

COMO content strategist, QUERO to see which knowledge informed a generated script, PARA an off-brand output can be diagnosed rather than guessed at.

## Context

`knowledge-engine.md` §4 requires retrieval traces; FR-IN05 requires each generated script to be traceable to the context and prompt version that produced it.

## Acceptance criteria

- **AC-1** Each retrieval records the query, the chunk identifiers returned and their scores.
- **AC-2** The trace is linked to the generation that consumed it.
- **AC-3** Traces are tenant-scoped and subject to the retention policy rather than kept indefinitely.

## BDD examples

- EX-P9-08a GIVEN a generated script, WHEN its trace is read, THEN the chunks that informed it are identifiable.

## Verification gate

Integration tests linking trace to generation.
