## User story

COMO frontend engineer, QUERO primitivos de gráfico que possuam paleta, eixos e tooltip, PARA que analytics fale a linguagem visual da VYRA e trocar Recharts seja uma mudança em um pacote.

## Context

`ADR-0035` selects Recharts via shadcn Charts and closes `OQ-P15-02` and `ASM-P15-01`, which had left the charting library open since ADR-0003. `VYRA_PRODUCT_EXPERIENCE.md` §12.2 fixes the chart-selection table and §12.3 the anatomy; the prohibitions matter as much as the selections.

## Acceptance criteria

- **AC-1** A chart primitive family exists — line, multi-line, area (single series), horizontal bar, stacked horizontal bar, meter, sparkline and calendar heat grid — each with a VYRA-shaped API. Recharts props are not exposed through the wrapper.
- **AC-2** The boundary holds: a direct import of Recharts or `shadcn/charts` from anywhere outside `packages/ui` fails the boundary lint from `P1.03`, naming the file.
- **AC-3** The prohibited set is not expressible: there is no pie, donut, radar, 3D, dual-axis or stacked-area primitive, and a bar chart's value axis cannot be given a non-zero baseline.
- **AC-4** Anatomy follows §12.3: transparent plot, horizontal grid at `border-subtle` only, no axis lines, `mono-sm` tertiary ticks capped at six on the value axis, inline end-labels at ≤ 3 series and a wrapping legend at ≥ 4.
- **AC-5** The palette comes from `viz-1`…`viz-8` in fixed order and never re-orders between renders; the five platform channels keep their fixed assignment from §5.4 so a colour means the same channel on every screen.
- **AC-6** Tooltips render at `e3` with a series swatch, label and tabular value, are keyboard reachable, follow the crosshair and never cover the hovered point. Gradient use is limited to the single sanctioned single-series area fill at 14% → 0% (§5.6).

## BDD examples

- EX-P19-01 GIVEN a screen importing Recharts directly, WHEN the boundary lint runs, THEN it fails naming the file.
- EX-P19-03 GIVEN a chart with four series, WHEN it renders, THEN a legend appears and each series is distinguishable by marker as well as colour.
- EX-P19-10 GIVEN a developer attempts to render a donut chart, WHEN the code is compiled, THEN no such primitive exists.

## Verification gate

Eight chart primitives render from VYRA-shaped props; the boundary lint turns red on a seeded direct Recharts import; no prohibited chart type exists in the API; the fixed palette order and channel assignment are asserted; tooltips are keyboard reachable; the gradient budget is enforced.
