## User story

COMO security reviewer, QUERO background jobs to run under the same tenancy enforcement as requests, PARA an asynchronous path cannot become the hole in RLS.

## Context

`architecture.md` §5 layer 2 requires every request and job to open its transaction with the tenant setting applied. P2.06 built the primitive; this story makes workers use it.

## Acceptance criteria

- **AC-1** Every job executes inside the `TenantContext` primitive from P2.06.
- **AC-2** A message lacking tenant context is rejected rather than processed with an unset GUC.
- **AC-3** Correlation identifiers propagate from the originating request through the outbox into the job (`observability.md` §2).
- **AC-4** Workers are stateless and persist nothing on local disk (NFR-11).

## BDD examples

- EX-P7-05 GIVEN a worker job, WHEN it runs, THEN it executes inside a tenant-scoped transaction exactly as an HTTP request would.
