## User story

COMO content strategist, QUERO knowledge chunked, versioned and deduplicated, PARA reprocessing a source does not silently duplicate its influence.

## Context

`knowledge-engine.md` §3 covers versioning, provenance and deduplication. FR-KN04 additionally requires processing status and reprocessing semantics.

## Acceptance criteria

- **AC-1** Chunks carry their source, version and provenance offsets.
- **AC-2** Reprocessing a source creates a new version rather than mutating chunks in place.
- **AC-3** Duplicate content is detected and not embedded twice for the same tenant.
- **AC-4** Chunk parameters come from configuration rather than literals.

## BDD examples

- EX-P9-03a GIVEN a source reprocessed without content change, WHEN chunking runs, THEN no duplicate chunk set is created.
