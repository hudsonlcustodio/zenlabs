## User story

COMO operations manager, QUERO render status resolved by polling with webhooks as an accelerator, PARA a missing or forged webhook cannot strand or mislead the pipeline.

## Context

`provider-architecture.md` §7 and §8; ADR-0031 treats webhooks as untrusted hints. OQ-P11-01 leaves the HeyGen webhook contract gated.

## Acceptance criteria

- **AC-1** Polling resolves render status on a configured interval and is the authoritative path.
- **AC-2** A verified webhook triggers an immediate status check rather than supplying the status directly (ADR-0031).
- **AC-3** T11 fires only when the provider reports a completed billable generation, per the T11 precondition.
- **AC-4** GATE-HG04 is recorded; absence of webhooks degrades latency, not correctness.

## BDD examples

- EX-P11-05a GIVEN a webhook claiming completion, WHEN it is processed, THEN the provider is queried before T11 fires.
