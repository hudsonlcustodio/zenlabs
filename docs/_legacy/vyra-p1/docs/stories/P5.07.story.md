## User story

COMO architect, QUERO a check that every generation path passes the consent guard, PARA a new generation entry point cannot silently skip governance.

## Context

FF-30 requires consent enforcement before every generation. The guard primitive must be the only way to reach a generation path, so the check is enumerable.

## Acceptance criteria

- **AC-1** Generation entry points are enumerable from code rather than from a maintained list.
- **AC-2** An entry point not passing the consent guard fails FF-30, naming the path.
- **AC-3** The check covers voice synthesis and video render independently, since both are generations.
- **AC-4** The guard evaluates consent, twin state and voice clone state together, not consent alone.

## BDD examples

- EX-P5-02 GIVEN a new generation entry point without a consent guard, WHEN CI runs, THEN FF-30 fails naming the path.

## Verification gate

FF-30 green on the clean tree and red on a seeded unguarded path.
