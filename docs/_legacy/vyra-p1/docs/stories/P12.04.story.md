# Story P12.04 — Tenant MANUAL/AUTO policy for client acceptance only

- **Story ID**: `P12.04`

## User story

COMO administrator, QUERO the tenant automation setting scoped strictly to client acceptance, PARA convenience never becomes a governance hole.

## Context

FR-AP06: a tenant's AUTO video-approval setting skips only the tenant's own acceptance step, never VYRA QA. §2.5 draws the same line. FR-AP03 keeps minimum quality controls in AUTO mode.

## Acceptance criteria

- **AC-1** The tenant setting affects only T05 and T15, and only the tenant's own acceptance.
- **AC-2** AUTO script approval additionally requires brand compliance to have passed (P10.06).
- **AC-3** AUTO video approval requires a passing QA record; it does not substitute for one.
- **AC-4** The setting is administered through a Control route and every change is audited.

## BDD examples

- EX-P12-04 GIVEN a tenant with AUTO script approval and a failing brand verdict, WHEN T05 is evaluated, THEN system approval is refused.

## Verification gate

Class 5 policy coverage green for both AUTO paths.
