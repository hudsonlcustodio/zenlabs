## User story

COMO frontend engineer, QUERO o tema carbono como canônico e o claro como puro remapeamento de tokens, PARA que exista um único design e não dois, e que o contraste de ambos seja provado sem navegador.

## Context

`VYRA_PRODUCT_EXPERIENCE.md` §4.6 makes light a token remap rather than a second design, and §5.5 fixes the contrast contract. Because the token layer is pure data, contrast can be computed as a unit test — which is what makes `NFR-14` checkable at wave 2 rather than at wave 12.

## Acceptance criteria

- **AC-1** The carbon theme is the default and is applied without a flash: the theme resolves server-side from the user profile, falls back to `prefers-color-scheme`, and falls back again to carbon. No theme flash occurs on first paint.
- **AC-2** The light theme redefines **only** semantic tokens, exactly the set tabulated in §4.6. A component file changed to support light is a defect; the theme test asserts zero component-level theme branching.
- **AC-3** The user's theme choice is persisted on the profile so it survives devices, and an explicit choice always overrides the system preference in both directions.
- **AC-4** A **contrast conformance test** computes every semantic foreground/background pair in **both** themes and asserts the §5.5 minimums: 4.5:1 body text, 3:1 for ≥ 24px display and for icons and control boundaries, 3:1 for chart series against the plot background, and 3:1 for the focus ring against both its neighbours. It runs without a browser.
- **AC-5** `prefers-contrast: more` raises every border token one step and text one step, and the raised set is included in the contrast test.

## BDD examples

- EX-P18-02 GIVEN the light theme, WHEN the contrast test runs over every semantic pair, THEN every pair meets its §5.5 minimum.
- EX-P18-11 GIVEN a user with an explicit light preference and a dark system setting, WHEN a page renders, THEN it renders light with no flash of dark.

## Verification gate

Both themes resolve with no flash; the contrast test is green for every semantic pair in both themes and in the raised-contrast set, and turns red on a seeded token change that breaks a minimum; zero component-level theme branching is asserted.
