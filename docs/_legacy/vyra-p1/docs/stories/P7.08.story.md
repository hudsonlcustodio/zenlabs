## User story

COMO architect, QUERO a check that every webhook route verifies signature and dedupes, PARA a new provider webhook cannot ship unguarded.

## Context

FF-24 requires every webhook to be idempotent and signature-gated.

## Acceptance criteria

- **AC-1** Webhook routes are enumerable, and one lacking signature verification fails FF-24 naming the route.
- **AC-2** A webhook route lacking `provider_event_id` deduplication fails FF-24.
- **AC-3** The check runs in the fitness-function stage from P1.06.

## BDD examples

- EX-P7-03 GIVEN a webhook route added without signature verification, WHEN CI runs, THEN FF-24 fails naming the route.

## Verification gate

FF-24 green on the clean tree and red on each seeded omission.
