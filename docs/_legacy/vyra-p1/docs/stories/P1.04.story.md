- **Story ID**: `P1.04`

## User story

COMO implementing agent, QUERO one zero-I/O root for schemas, DTOs, event payloads and error codes, PARA contracts never fork between API, workers and UI.

## Context

`architecture.md` §2.2 makes `contracts` the only package with no dependencies. `api-contracts.md` §1.1 fixes a stable error-code set.

## Acceptance criteria

- **AC-1** Zod is the single schema authority; no parallel validation library is introduced.
- **AC-2** The stable error codes of `api-contracts.md` §1.1 are declared here and nowhere else.
- **AC-3** Domain event payload types have a declared home even though no event is emitted until P8.
- **AC-4** The package's public export surface is snapshot-tested so a breaking change is visible in review.

## BDD examples

- EX-P1-04a GIVEN an error code string used in an app, WHEN it is not exported by `contracts`, THEN typecheck fails.
