## User story

COMO implementing agent, QUERO audio synthesised through the voice port, PARA the voice vendor is replaceable and verification is respected.

## Context

`provider-architecture.md` §4 and `prd.md` §9.2. IVC is the default path and PVC the premium option; PVC requires owner verification, and FR-ID06 forbids designing any bypass.

## Acceptance criteria

- **AC-1** The adapter implements the voice port declared in P4.01 with no vendor type crossing into the domain (FF-03).
- **AC-2** Both IVC and PVC clone references are usable for synthesis.
- **AC-3** Synthesis is refused when the voice clone is not verified-ready (FF-12).
- **AC-4** Provider failures map to the P4.02 taxonomy, distinguishing terminal-with-no-output from other classes.
- **AC-5** GATE-EL01 is recorded; the adapter runs against mocks until workspace requirements are confirmed.

## BDD examples

- EX-P11-01a GIVEN an unverified voice clone, WHEN synthesis is requested, THEN it is refused before any provider call.
