## User story

COMO security reviewer, QUERO dynamic SQL construction rejected before it exists, PARA injection and accidental RLS bypass share the same root cause.

## Context

FF-22 forbids string-built SQL. Introducing it now means the first raw query written in a later epic is already constrained.

## Acceptance criteria

- **AC-1** String concatenation or template interpolation into a SQL execution path fails the check.
- **AC-2** Parameterised and builder-based queries pass unchanged.
- **AC-3** Any deliberate raw-SQL escape hatch is explicitly listed and reviewed rather than implicitly tolerated.

## BDD examples

- EX-P2-09a GIVEN a query assembled by string interpolation, WHEN CI runs, THEN FF-22 fails naming the file.

## Verification gate
