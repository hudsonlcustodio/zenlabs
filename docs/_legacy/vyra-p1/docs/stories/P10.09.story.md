## User story

COMO security reviewer, QUERO injection containment asserted by test and by check, PARA RISK-06 is mitigated in a way that survives future prompt work.

## Context

FF-27 requires prompt injection to be contained. `testing-strategy.md` class 13 lists prompt-injection containment among the required security tests.

## Acceptance criteria

- **AC-1** FF-27 fails when prompt assembly occurs outside the P10.01 builder.
- **AC-2** Class 13 tests assert that instruction-shaped content in retrieved chunks does not alter behaviour.
- **AC-3** Containment is asserted for every task in the taxonomy, not only script generation.
- **AC-4** A new task added without going through the builder fails the check.

## BDD examples

- EX-P10-01 GIVEN a knowledge chunk containing instruction-shaped text, WHEN the containment test runs, THEN behaviour is unchanged and FF-27 passes.
