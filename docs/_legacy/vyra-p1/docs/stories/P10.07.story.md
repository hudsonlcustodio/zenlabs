## User story

COMO platform operator, QUERO LLM token cost recorded per generation, PARA the contribution calculation in FR-PC03 has real inputs.

## Context

`intelligence-engine.md` §7 and FR-PC02, which lists LLM among the providers whose cost is recorded. GATE-COST01 covers fields a provider may not expose.

## Acceptance criteria

- **AC-1** Each generation writes a `provider_cost_entry` referencing the attempt and the resolved model.
- **AC-2** Where the provider does not expose cost, the entry records null with a reason rather than an estimate (GATE-COST01).
- **AC-3** Cost recording never writes into the usage ledger; the two remain separate rows (module 19 invariant).

## BDD examples

- EX-P10-07a GIVEN a completed LLM generation, WHEN the cost ledger is read, THEN an entry exists referencing the attempt and the resolved model.

## Verification gate

Integration tests asserting separation from the usage ledger.
