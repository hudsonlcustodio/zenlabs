## User story

COMO frontend engineer, QUERO virtualização que preserve semântica de tabela e navegação por teclado através da fronteira virtual, PARA que um ledger de dez mil linhas continue acessível.

## Context

`VYRA_PRODUCT_EXPERIENCE.md` §14.4 requires that a virtualised grid keeps real table semantics with `aria-rowcount` and that keyboard navigation works across the virtual boundary — the failure mode most virtualisation libraries ship with. The audit ledger (`FR-C07`) and the usage ledger (`FR-C04`) are the screens that need it.

## Acceptance criteria

- **AC-1** Row virtualisation engages above a configured threshold (default 200 rows) and is transparent to the grid's public API.
- **AC-2** A virtualised grid keeps real `<table>` semantics with correct `aria-rowcount`, `aria-rowindex` and `aria-colcount`, so a screen reader reports position within the full set rather than within the rendered window.
- **AC-3** Keyboard navigation — `↑ ↓ Home End PageUp PageDown` — works across the virtual boundary: focus lands on the correct row, that row is rendered before focus moves, and the row's position is announced.
- **AC-4** The four truncation strategies of §14.5 are declarable per column — `truncate-end`, `truncate-middle`, `wrap-2`, `none` — and a truncated cell is always recoverable through a tooltip, the drawer or a copy action.
- **AC-5** A performance assertion records time-to-interactive for a 10,000-row fixture and fails above a recorded budget, so virtualisation is proven rather than assumed.

## BDD examples

- EX-P19-04 GIVEN a grid of 5,000 rows, WHEN a keyboard user presses `PageDown` past the virtual boundary, THEN focus lands on the correct row and is announced.
- EX-P19-16 GIVEN a virtualised grid, WHEN a screen reader reports position, THEN it reports the index within the full row count, not the rendered window.

## Verification gate

Virtualisation engages above the threshold; `aria-rowcount`/`aria-rowindex` correct against the full set; keyboard navigation crosses the virtual boundary with correct focus and announcement; per-column truncation strategies declared and recoverable; the 10,000-row budget assertion passes.
