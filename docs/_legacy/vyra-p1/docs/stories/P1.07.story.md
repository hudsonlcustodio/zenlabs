## User story

COMO security reviewer, QUERO committed secrets caught by the pipeline, PARA a leaked provider key is unrecoverable once pushed.

## Context

FF-19 requires that no secret is committed. `security-architecture.md` §4 places runtime credentials in Secrets Manager.

## Acceptance criteria

- **AC-1** Secret scanning runs on every pipeline execution and blocks on detection.
- **AC-2** A seeded fake credential turns the stage red in the test fixture and the finding is reported without echoing the value.
- **AC-3** History scanning is configured, not only diff scanning.

## BDD examples

- EX-P1-02 GIVEN a file containing a fake AWS-shaped key, WHEN CI runs, THEN FF-19 fails before any other stage.

## Verification gate

FF-19 passes clean and fails on the seeded fixture.
