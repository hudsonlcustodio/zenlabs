# Story P11.09 — FF-21 no media on the local filesystem

- **Story ID**: `P11.09`
- **Epic**: `P11` (`docs/epics/epic-P11.md`)
- **Status**: `draft`
- **Wave**: 6
- **Priority**: P0
- **Story points**: 3
- **Depends on**: `P11.02`
- **IMPLEMENTATION NOT STARTED**

## User story

COMO architect, QUERO a check that no media path touches local disk, PARA NFR-11 survives every future media feature.

## Context

FF-21 requires that no media persists on the local filesystem. NFR-11 makes applications stateless.

## Acceptance criteria

- **AC-1** A write of media content to a local path fails FF-21, naming the write.
- **AC-2** Temporary-file APIs used on media paths fail the check as well as explicit writes.
- **AC-3** The check runs in the fitness-function stage from P1.06.

## BDD examples

- EX-P11-03 GIVEN any generation path, WHEN CI runs, THEN FF-21 confirms nothing is written to local disk.

## Verification gate

FF-21 green on the clean tree and red on a seeded local write.

## Architecture references

- `docs/architecture/fitness-functions.md` FF-21
- `docs/architecture/prd.md` NFR-11

## Out of scope

- Non-media temporary files, which are out of this check's scope.
