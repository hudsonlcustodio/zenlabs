# Story P16.03 — A runbook for every alarm, including DLQ redrive, ingestion recovery and production restore

- **Story ID**: `P16.03`
- **Epic**: `P16` (`docs/epics/epic-P16.md`)

- **Depends on**: `P16.02`

## User story

COMO on-call operator, QUERO every alarm to arrive with the procedure that resolves it, PARA an alert is an instruction rather than an interruption.

## Context

`implementation-sequencing.md` Phase 15 makes "every alarm in `observability.md` §4 exists and has a runbook" the definition of done. Three procedures were explicitly deferred to this story: DLQ redrive from `P7.03`, the ingestion manual-recovery path from `P11.06` AC-6, and the production snapshot restore from `P2.02` and `P2.11`.

## Acceptance criteria

- **AC-1** Every alarm in `observability.md` §4 resolves to a runbook entry; an index test fails when an alarm has none.
- **AC-2** The DLQ redrive runbook states how to reprocess safely given that every handler is idempotent under the `P7.05` keys, closing the `P7.03` deferral.
- **AC-3** The ingestion manual-recovery runbook covers T11c and states explicitly that recovery never re-renders and never reverses a commit, matching guard G-5 and FF-32, closing the `P11.06` AC-6 deferral.
- **AC-4** The production snapshot restore runbook is exercised as a drill, which `aws-topology.md` §4 calls a scheduled operational exercise rather than an assumption, closing the `P2.02` and `P2.11` deferrals.
- **AC-5** No runbook contains a credential, provider API key or connection string; they name the secret path in Secrets Manager per `security-architecture.md` §4.

## BDD examples

- EX-P16-02 GIVEN any alarm listed in `observability.md` §4, WHEN the runbook index is checked, THEN a runbook entry exists for it and names an owner action.
- EX-P16-07 GIVEN a message resting in a DLQ, WHEN the redrive runbook is followed, THEN the message is reprocessed with a single effect under the `P7.05` keys.

## Verification gate

Runbook-index test green against the `observability.md` §4 alarm table; one recorded restore drill and one recorded DLQ redrive rehearsal.
