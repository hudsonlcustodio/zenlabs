## User story

COMO QA reviewer, QUERO every route tested against every role, PARA a permission regression is caught by the suite rather than by a customer.

## Context

## Acceptance criteria

- **AC-1** The suite is driven by the route manifest, so new routes are covered automatically.
- **AC-2** Each route-by-role cell has an explicit expected outcome; an unspecified cell fails the suite.
- **AC-3** Cross-tenant attempts are included for tenant-scoped roles.
- **AC-4** The suite runs on every pipeline execution per `testing-strategy.md` §6.
