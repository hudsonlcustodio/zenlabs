## Context

`workflows-state-machines.md` §2.1 fixes the states, including `INGESTING` which exists so that generated and stored are distinguishable (ADR-0034, FR-WF02).

## Acceptance criteria

- **AC-1** The states of `workflows-state-machines.md` §2.1 are implemented exactly, including `INGESTING` and the alternates in FR-WF03.
- **AC-2** `BLOCKED` carries a reason, and `ingestion_failed` is distinguishable from the T22 reasons.
- **AC-3** The state column is not writable through any repository path (enforced in P8.11).
- **AC-4** The item references its request, its script versions and its generation attempts.

## BDD examples
