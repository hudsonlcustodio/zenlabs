## User story

COMO administrator, QUERO to record payment status manually, PARA the commercial reality of external payment is represented without a gateway.

## Context

FR-BL01 to FR-BL04: no gateway in MVP, payments occur externally, an admin records pending, paid, overdue or suspended, and activation and suspension behaviours are modelled.

## Acceptance criteria

- **AC-1** Subscription carries plan, billing cycle boundaries and payment status.
- **AC-2** Payment status transitions among pending, paid, overdue and suspended are recorded by an administrator and audited.
- **AC-3** Suspension makes the T01 precondition `subscription active` fail, blocking new requests.
- **AC-4** No code path contacts a payment provider, and none exists to contact.

## BDD examples

- EX-P6-06a GIVEN a suspended subscription, WHEN a content request is attempted, THEN T01's precondition fails.
