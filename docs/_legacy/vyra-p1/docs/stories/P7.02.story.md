## User story

COMO platform operator, QUERO a relay that publishes outbox rows to queues reliably, PARA at-least-once delivery is guaranteed and duplicates are handled downstream.

## Context

ADR-0009. The relay is the only publisher; direct queue writes from application code would bypass the transactional guarantee.

## Acceptance criteria

- **AC-1** The relay publishes unpublished rows in order per aggregate and marks them published only after the broker accepts them.
- **AC-2** A relay crash mid-publish results in redelivery rather than loss, and downstream idempotency absorbs it.
- **AC-3** Direct queue publication from application code is rejected by lint or by package boundaries.
- **AC-4** Relay lag is exposed as a metric for the P16.02 alarms.

## BDD examples

- EX-P7-02a GIVEN a relay crash after broker acceptance but before marking published, WHEN it restarts, THEN the message is redelivered and handled once.
