# ZENLABS UX Foundation Prototype

Static, dependency-free clickable prototype for validating density and hierarchy.

Screens:
- Operação
- Nova Produção
- Análise / Packs
- Production Monitor
- Clientes
- Digital Twin

Purpose:
- validate information hierarchy;
- validate compact typography;
- validate “little text” rule;
- validate core navigation.

It is not production code and does not define backend behavior.
